# 更新日志 / Changelog

## v0.1.0 — 2026-09-18

### 中文

- 发布 ECC Buildings 首个带版本号的公开预览，包含城市、公寓楼、电气室和低压开关柜探索路径。
- 提供中英文切换、场景热点、电气室全景环视，以及 GitHub Pages 在线预览。
- 整理仓库目录：技术文档放入 `docs/`，媒体生产脚本放入 `scripts/`，可编辑模型放入 `models/`；历史资料与本地渲染文件保存在 Git 忽略的 `.local/`。
- 补充贡献指南、PR 模板、文件格式约定与仓库目录说明。

### English

- First versioned public preview of ECC Buildings, covering the city, apartment building, electrical room, and conceptual low-voltage switchgear journey.
- Includes Chinese and English, scene hotspots, an interactive room panorama, and a GitHub Pages preview.
- Organizes technical documentation in `docs/`, media production scripts in `scripts/`, and editable scene masters in `models/`; historical and local render files are kept in the Git-ignored `.local/` directory.
- Adds contribution guidance, a pull request template, file-format rules, and a repository layout guide.
